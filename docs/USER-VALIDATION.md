# Five-person comprehension check — blank observation sheet

This file is a plan/template, not completed research. Use fictional cases only. Do not record a participant's name, email, order information or sensitive complaint contents here.

Show the demo to a nontechnical shopper. Give tasks without explaining the interface first:

1. Identify the two recorded explanations and the pickup they describe.
2. Find why a second example has different pickup attempts and should not be treated as the same disagreement.
3. Prepare a follow-up using the explicitly labeled rule review or actual configured AI flow.
4. Save a manual explanation or keep the reason unknown; explain what “resolved task” does and does not mean.
5. Add the fictional example source, inspect changed context, then export a brief and review its support draft.

Ask: “What would you do next with this brief?” and “What information do you still need?” Do not lead users toward positive feedback.
