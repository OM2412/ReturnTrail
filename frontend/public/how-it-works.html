THE RETURN DESK / HOW IT WORKS

Keep the words.
Find the missing context.

A failed return pickup can have more than one recorded explanation. ReturnTrail demonstrates how to compare those claims and prepare a source-linked brief for a support conversation.

1. Read the original records

Each fictional document keeps its original words and supporting quotation. A claim about one pickup attempt is compared with the same attempt, rather than another attempt on the order.

2. Follow the relationships

The evidence path links the case, order, returned item, return request, pickup attempt, statement and source document. The Connections page shows the matched paths; the 3D story is an illustration.

3. Ask the next question

A supported disagreement or explicit missing reason can create a local follow-up question. Record a manual explanation or keep it unknown. A manual note is not independent verification.

4. Notice when context changes

New fictional evidence can need a fresh review. Earlier sources and replies remain in history. Context lab shows which sources a saved task covered and lets you temporarily set one source aside without changing the saved case.

5. Take a brief with you

Read the fresh case brief, print/save it as a PDF or download its JSON. A source-linked message draft can be copied for review. Nothing is automatically sent.

What can this demo assess?

The supported conflict is customer cancellation versus courier unavailability for the same pickup. Explicit UNKNOWN records can request missing context. No finding under these rules does not prove an explanation or resolve a whole case.

Can I use my real receipts?

This release is a fictional practice workspace. It does not upload or parse PDF receipts, screenshots, personal complaints or inboxes. Do not paste personal information.

Do I need an account?

No. The guest demo is temporary. Optional configured Google or GitHub sign-in opens a separate saved demo workspace. Guest work is not automatically imported; export it first.

Will ReturnTrail obtain my refund?

No. The demo organizes recorded claims and questions. It does not contact a merchant, determine fault, submit a grievance or issue a refund.
